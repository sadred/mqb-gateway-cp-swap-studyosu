- **Proje:** mqb_contitool — Continental VAG MQB J533 (3Q0 907 530) Gateway Toolkit
- **Yazar:** PerkTheFox
- **Depo:** https://github.com/perkthefox/mqb_contitool

- **Telegram:** https://t.me/perkthefox
- **Bu proje için fork:** https://github.com/sadred/mqb_contitool

Dosya **değiştirilmeden** gömülmüştür (yalnız `motor/` altına kopyalanmıştır). Güncellemek için:

```bash
gh repo sync sadred/mqb_contitool          # fork'u upstream ile eşitle
cp <fork>/conti_cp_tool.py motor/          # yeni sürümü kopyala
```

Motorun şartları: **ücretsiz**, **satılamaz**, atıf korunmalıdır (yukarıdaki bağlantılar).
Ayrıntılar için `LICENSE.md` ve motorun kendi `--help` çıktısındaki başlığa bakın.
